# Netflix Clone

A front-end Netflix clone built with HTML, CSS and vanilla JavaScript for an MCA project.

## Features
- Landing page with email capture
- Sign up / Sign in (localStorage)
- Home page with hero trailer, Top 10, Continue Watching, My List, Recently Viewed
- Movies & TV Shows category pages with genre filter
- Movie detail page with hover trailer and My List toggle
- Search and Profile pages

## How to run
Open `index.html` in a browser (or use any static server).

## Notes
- All data is client-side only.
- Passwords are stored in plain text in localStorage (demo only).
